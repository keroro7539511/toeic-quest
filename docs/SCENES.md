# 情境分類（scene id）

開場句題庫（data/gist/）與情境攻略本（data/scenes.js）共用這些 id：

| id | 情境 | 常見於 |
|---|---|---|
| order_problem | 訂單、出貨、送貨問題 | Part 3 / 4 |
| schedule_change | 預約、改期、時程調整 | Part 3 / 4 |
| equipment_problem | 設備故障、IT 支援、系統問題 | Part 3 / 4 |
| store_purchase | 購物、詢價、退換貨 | Part 3 |
| restaurant_hotel | 餐廳、飯店、訂位、外燴 | Part 3 / 4 |
| job_hr | 求職面試、人事、新人訓練 | Part 3 / 4 |
| meeting_project | 會議、專案進度、工作分配 | Part 3 / 4 |
| event_planning | 活動、研討會、派對籌備 | Part 3 / 4 |
| travel_transport | 出差、機票、交通 | Part 3 / 4 |
| office_facility | 辦公室搬遷、裝修、設施維護 | Part 3 / 4 |
| budget_sales | 預算、業績、行銷策略 | Part 3 / 4 |
| real_estate | 租屋、房地產、店面 | Part 3 |
| health_appointment | 診所、醫療、牙醫預約 | Part 3 / 4 |
| announcement | 公告、廣播（商店、機場、公司） | Part 4 |
| voicemail | 電話留言 | Part 4 |
| advertisement | 廣告 | Part 4 |
| tour_guide | 導覽（工廠、博物館、城市） | Part 4 |
| news_broadcast | 新聞、交通、天氣報導 | Part 4 |
| speech_intro | 演講、致詞、介紹講者、頒獎 | Part 4 |
