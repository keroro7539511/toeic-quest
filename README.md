# TOEIC Quest 🐣→👑

遊戲化的多益練習網頁（目標 450 → 750）。純前端，不用安裝任何東西。

## 開始使用

直接用 **Chrome** 或 **Safari** 打開 `index.html`。

想用手機練：在這個資料夾執行 `python3 -m http.server 8000`，手機連同一個 Wi-Fi，打開 `http://<電腦IP>:8000`。

## 模式

**📝 多益模擬考**：完整 200 題、題型與題數跟正式多益相同。聽力約 50 分鐘自動播放、只播一次；閱讀 75 分鐘計時、可跳題標記。交卷後有估計分數、CEFR 等級、各 Part 正確率與逐題詳解。

**🎯 專項模擬（考試模式）**：只練聽力或只練閱讀。

- 🎧 **聽力小模考**：從練習題庫抽約 26 題（Part 1×3、Part 2×8、Part 3×3 組、Part 4×2 組），依考試順序自動播放、只播一次，Part 3/4 每段開播前有 5 秒預讀題目，聽完由播音員唸題目、每題 8 秒作答時間（完整模擬考也一樣）。
- 📖 **閱讀小模考**：約 25 題（Part 5×10、Part 6×1 篇、Part 7 單篇×2＋多篇×1），照正式考試比例計時（75 分 / 100 題）。
- 小模考每次優先抽還沒考過的題目，交卷後有粗估分數、各 Part 正確率和詳解。
- 🎧 聽力完整模擬 / 📖 閱讀完整模擬：直接進入模擬考的 100 題聽力或閱讀。

Part 3/4 練習另有：預讀倒數（可在設定調整秒數）、逐句精聽（附中文翻譯，資料在 `data/trans/`）、逐字稿難字註解、重寫、暫停與語速切換。

另有 XP / 等級、每日目標與連續天數、成就、粗估分數、單字圖鑑。

快捷鍵：`1-4` 或 `A-D` 作答、`Enter` 下一題、`R` 重播音檔。

## 新增題目

題庫在 `data/`，格式見 `docs/QUESTION_SPEC.md`。請**加在陣列最後面**（題目用順序當 ID，插在中間會打亂學習紀錄）。
新增後執行 `node tools/validate.js` 檢查格式、答案分布與模擬考題數。
Part 3/4 逐字稿的難字中文註解在 `data/gloss/`（key 為 `p3:0`、`MOCK1:p4:2` 這類題組編號），新增題組時記得一起補。
改完題目後重新產生語音（見下方），新題目才會有 AI 語音。

## 語音

聽力使用 [edge-tts](https://github.com/rany2/edge-tts) 預先產生的 AI 語音（`audio/`），美、英、澳、加四種口音混合，接近真實考試。
沒有音檔的句子會自動改用瀏覽器內建語音。

重新產生（只會補新題目，約 1 分鐘）：

```bash
python3 -m venv .venv && .venv/bin/pip install edge-tts   # 第一次才需要
.venv/bin/python tools/gen_audio.py
```

edge-tts 是借用微軟 Edge 線上語音的非官方工具，產生時需要網路；產生好的 MP3 可以離線播放。

進度存在瀏覽器的 localStorage，換瀏覽器或清除網站資料會重置。
