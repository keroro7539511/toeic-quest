# TOEIC Quest 🐣→👑

遊戲化的多益練習網頁（目標 450 → 750）。純前端，不用安裝任何東西。

## 開始使用

直接用 **Chrome** 或 **Safari** 打開 `index.html`。

想用手機練：在這個資料夾執行 `python3 -m http.server 8000`，手機連同一個 Wi-Fi，打開 `http://<電腦IP>:8000`。

## 模式

**📝 多益模擬考**：共 3 回題本，每回完整 200 題、題型與題數跟正式多益相同。聽力約 50 分鐘自動播放、只播一次；閱讀 75 分鐘計時、可跳題標記。交卷後有估計分數、CEFR 等級、各 Part 正確率與逐題詳解。

**🎯 專項模擬（考試模式）**：只練聽力或只練閱讀。

- 🎧 **聽力小模考**：從練習題庫抽約 26 題（Part 1×3、Part 2×8、Part 3×3 組、Part 4×2 組），依考試順序自動播放、只播一次，Part 3/4 每段開播前有 5 秒預讀題目，聽完由播音員唸題目、每題 8 秒作答時間（完整模擬考也一樣）。
- 📖 **閱讀小模考**：約 25 題（Part 5×10、Part 6×1 篇、Part 7 單篇×2＋多篇×1），照正式考試比例計時（75 分 / 100 題）。
- 小模考每次優先抽還沒考過的題目，並依難度標籤照 簡單 30%／中等 40%／困難 30% 抽題；看圖題排在 Part 3/4 最後、Part 7 單篇在前多篇在後，跟正式考試順序一樣。交卷後有粗估分數、各 Part 正確率和詳解。
- 🎧 聽力完整模擬 / 📖 閱讀完整模擬：直接進入模擬考的 100 題聽力或閱讀。

| 練習 | 題庫 |
|---|---|
| 📷 Part 1 看圖描述 | 80 張照片 |
| 🎧 Part 2 應答問題 | 90 題 |
| 💬 Part 3 對話（含三人、看圖、言外之意） | 50 組 / 150 題 |
| 📻 Part 4 獨白（含看圖） | 54 組 / 162 題 |
| ✏️ Part 5 句子填空 | 130 題 |
| 📄 Part 6 短文填空（含句子插入） | 14 篇 / 56 題 |
| 📰 Part 7 閱讀（單篇、雙篇、三篇） | 23 組 / 84 題 |
| 📚 單字冒險（SRS） | 320 字 |
| 🎯 開場猜情境（只聽開場一兩句判斷情境） | 90 題 |

| ✍️ 聽寫、👾 錯題怪物、🐉 Boss 戰 | |

Part 3/4 練習另有：預讀倒數（可在設定調整秒數）、逐句精聽（附中文翻譯，資料在 `data/trans/`）、逐字稿難字註解、重寫、暫停與語速切換。

另有 XP / 等級、每日目標與連續天數、成就、粗估分數、單字圖鑑。

快捷鍵：`1-4` 或 `A-D` 作答、`Enter` 下一題、`R` 重播音檔。

## 新增題目

題庫在 `data/`，格式見 `docs/QUESTION_SPEC.md`。請**加在陣列最後面**（題目用順序當 ID，插在中間會打亂學習紀錄）。
新增後記得在 `data/diff/` 補難度標籤，並執行 `node tools/validate.js` 檢查格式、答案分布、難度標籤與模擬考題數。
Part 3/4 逐字稿的難字中文註解在 `data/gloss/`（key 為 `p3:0`、`MOCK1:p4:2` 這類題組編號），新增題組時記得一起補。
改完題目後重新產生語音（見下方），新題目才會有 AI 語音。

## 語音

聽力使用 [edge-tts](https://github.com/rany2/edge-tts) 預先產生的 AI 語音（`audio/`），美、英、澳、加四種口音混合，接近真實考試。
沒有音檔的句子會自動改用瀏覽器內建語音。

重新產生（只會補新題目，約 1 分鐘）：

```bash
python3 -m venv .venv && .venv/bin/pip install edge-tts   # 第一次才需要
.venv/bin/python tools/gen_audio.py
```

edge-tts 是借用微軟 Edge 線上語音的非官方工具，產生時需要網路；產生好的 MP3 可以離線播放。

## 登入與排行榜

用 [Supabase](https://supabase.com)（免費方案）存每個人的進度和排行榜：Email + 密碼登入，進度跨裝置同步；排行榜比本週 XP、連續天數、模擬考最高分、累積答對。

- 連線設定在 `js/cloud-config.js`（publishable key 本來就是公開的，安全性靠資料表的 Row Level Security）。留空就不啟用登入，進度只存在瀏覽器。
- 第一次設定：在 Supabase 的 SQL Editor 執行 `supabase/setup.sql`；想限制只有特定 Email 能註冊，再執行 `supabase/allowlist.sql`（Email 名單不要寫進 repo）。
- 免費專案連續 7 天沒人使用會被暫停，到 Supabase 後台按 Restore 即可。

未登入時進度存在瀏覽器的 localStorage，換瀏覽器或清除網站資料會重置。
